Inside ADVO GO

Built for the way Indian businesses actually work

Every screen is designed for speed — keyboard-first, searchable, and printable the moment you need it.

01

Quick actions & global search

Press Esc for the quick-actions palette, Ctrl+K to search anything — items, parties, invoices — from anywhere in the app.

02

Real SQLite database

Your books live in a real SQLite file. Download the .db, open it in any SQLite tool, or restore from a JSON backup anytime.

Optional auto-backup keeps a fresh copy every 7 days. Restore takes one click — or import a .db file directly.
